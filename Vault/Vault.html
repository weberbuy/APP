🔐 為什麼連原始檔名都不外洩？

每個檔案在離開您的手機/電腦前，會先將「原始檔名、分類、備註、SHA-256 雜湊」以 AES-256-GCM 加密放入 WBVLT1 標頭，外部檔名統一混淆為 VLT-日期-時間-帳號-隨機碼.vlt。因此無論是樹莓派或 Google 雲端硬碟搜尋索引，都無法得知檔案真實名稱與內容。

🛟 離線緊急解密方式（當伺服器與網路都無法使用時）
  • 方法 A（使用本網頁離線解密）：直接用瀏覽器打開本頁 Vault.html，點擊左下方「選擇本機 .vlt 加密檔立即解密還原」。
  • 方法 B（使用 Server 專案內建的 Node.js CLI 工具）：在任何裝有 Node.js 的電腦執行： 
    node decrypt-cli.js ./data/Vault "您的加密主通行碼" ./restored_files

將專案內的 gas-vault.gs 貼至 Google Apps Script 並部署為「網頁應用程式（所有人可存取）」，即可與 `LifeSchedule` 一樣永久靜默雙軌備份至 Google 雲端硬碟的 WeberVault 資料夾。
